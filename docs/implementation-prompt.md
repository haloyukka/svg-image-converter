# AIへの実装依頼プロンプト

あなたはSVG描画とブラウザ画像処理に詳しいエンジニアです。同梱のdocs/requirements.mdを要求の正本とし、docs/validation.mdと実装を読み、SVG Image Converterを完成させてください。

## 必須条件

- GitHub Pages、ビルド不要、分割したHTML/CSS/JavaScript、ブラウザ内処理。
- 全要求は初期版対象。難しい要求を独断で削除したり、「完成」と表現しない。
- 現状は静止画中心の検証版。アニメーション、JS隔離、外部リソース許可制、AVIFの有効環境確保、実測負荷制御、全対象実機試験が未達。
- 実現できない入力は中止し理由を示す。JSやanimationを削除して成功扱いしない。
- Q42に従い、環境固有の非対応機能は無効化し理由と利用可能な環境を案内する。全環境で機能を無効にしたまま全要求達成としない。
- プリセットはJSONのみ。履歴はメタデータのみブラウザ保存。入力・結果バイナリを永続化しない。
- CDN/WASM可。固定バージョン、公式ソース・ライセンス・Pages上の動作を確認する。

## 作業順序

1. 要求追跡表を読み、実装と照合する。コードやUIがあるだけで検証済みにしない。
2. G01〜G08の小規模PoCを行い、再現SVGと客観的な合格条件を保存する。
3. SMIL/CSSの時間制御と静的フレーム化、JS実行前同意・隔離、外部参照の許可制とCORS処理を実装する。
4. GIF/WebP/APNGの動画エンコーダーを実装し、独立したデコーダーでフレーム数・遅延・ループを試験する。
5. AVIFを少なくとも1つの対象環境で生成できるようにする。MIME/マジックバイトを検証しPNGへの暗黙フォールバックを拒否する。
6. Worker、処理時間制限、総メモリ予算、キャンセル、ファイル毎の背景画像保持、英語文言の完全化、アクセシビリティを完成させる。
7. 添付5SVGとSMIL/CSS/JS/外部参照/悪意ある入力/大容量入力で試験する。対象環境の能力表を作る。
8. requirements.mdの追跡表とvalidation.mdを更新する。残課題があれば完成扱いしない。
9. GitHub Pages用ファイルとMarkdown、テスト、使用手順をZIPにまとめる。

## 再現性と安全性

任意JavaScriptのシークは自動で保証できない。制御可能な入力契約を設計し、要求との衝突があれば事実・代替案・残る要件を明記する。元要求を勝手に変更しない。sandbox="allow-scripts allow-same-origin"の安易な組合せや、信頼できないSVGのinnerHTML挿入を避ける。親DOM/ストレージ/通信へのアクセス制限を実テストする。無限ループを親画面ごと停止させる設計を採用しない。

まずdocs/validation.mdの再実行コマンドで基礎テストを行い、次にPoCへ進んでください。既存の成功テストを真似ただけのテストを増やさず、必要な新しい挙動・異常系を検証してください。
